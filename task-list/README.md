# Well Data Assistant POC: 5-week task list

Week 6 (Dec 21 to Dec 25) is for testing only. All build tasks finish by end of Week 5 (Fri Dec 18). Dec 25 is a holiday, and the daily load keeps running through it.

Decisions: pilot users start earlier (access opens Mon Dec 14). The two-week unattended-load window runs Mon Dec 14 to Fri Dec 25. Dec 7 to Dec 11 stabilizes the load. The load pipeline is frozen from Dec 14. Open in Excel: [WDA-POC-Task-List.xlsx](WDA-POC-Task-List.xlsx).

Source: Client Dependencies and Sharing Strategy and the Kickoff Agenda. Tasks marked (Mitsui) belong to Mitsui and are tracked here so we can chase them.
