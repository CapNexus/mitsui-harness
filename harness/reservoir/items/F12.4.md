# Per-question audit record via AgentCore Observability

Record, for every question, the named user, question, tool calls, SQL statement, timestamp and result row count using AgentCore Observability, including when the identity-propagation fallback is in use.

## User story

As an auditor, I want one audit record per question tied to a named person, so that I can trace any answer to who asked, what ran and how much data came back.

## Acceptance criteria (EARS)

1. When a question is answered, the system shall write an audit record containing the user, question, tool calls, SQL statement, timestamp and row count.
2. While the identity-propagation fallback is in use, the system shall tie each audit record to a named person.
3. If a field of the audit record cannot be populated, then the system shall emit an error metric identifying the missing field.
4. The system shall write the audit records to the encrypted destination from F12.1.
