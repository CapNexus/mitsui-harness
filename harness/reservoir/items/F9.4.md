# Table discovery and SQL authoring instructions

Write the assistant's instructions so it discovers tables, reads their descriptions, samples values, and then writes SQL.

## User story

As a well data analyst, I want the assistant to inspect tables before querying, so that its SQL uses real tables and values.

## Acceptance criteria (EARS)

1. When a question names no table, the system shall list candidate tables and read their descriptions before writing SQL.
2. When a column's values are unclear, the system shall sample values from that column before using it in a filter.
3. When the assistant has chosen tables, the system shall write a single SQL statement for the question.
