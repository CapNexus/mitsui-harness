# Validate the Bot Framework JWT on every request

Reject any request to `/api/messages` that lacks a valid Bot Framework JWT before it reaches the assistant.

## User story

As a security reviewer, I want unauthenticated requests rejected so that only Bot Framework traffic reaches the assistant.

## Acceptance criteria (EARS)

1. If a POST to `/api/messages` has no Bot Framework JWT, then the system shall reject it with a 401 response before invoking the assistant.
2. If a POST to `/api/messages` has an invalid or expired Bot Framework JWT, then the system shall reject it with a 401 response before invoking the assistant.
3. If a JWT has an audience or issuer that does not match the single-tenant bot, then the system shall reject the request.
4. When a request carries a valid Bot Framework JWT, the system shall pass it on for processing.
