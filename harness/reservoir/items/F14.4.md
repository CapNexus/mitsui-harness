# Estimate AWS run cost from actual usage

Produce an AWS run-cost estimate for the POC based on measured usage, for use in the readout.

## User story

As Mitsui's decision maker, I want a run-cost estimate from actual usage, so that I can decide whether to keep the resources.

## Acceptance criteria (EARS)

1. When the estimate is prepared, the system shall base it on actual AWS usage observed during the POC.
2. The estimate shall list cost per AWS service with the usage figure behind each line.
3. The estimate shall state its assumptions and the period of usage it covers.
