# Place the tools in the VPC with no path to the source databases

Put the tool Lambdas in their own VPC subnets with interface endpoints to Athena and logs and no route to the VPN, so the assistant layer can never reach Mitsui's databases.

## User story

As Venkat (DevOps), I want the tool Lambdas in their own subnets of the workload VPC, with interface endpoints to Athena and logs and no route to the VPN, so that the assistant layer can never reach Mitsui's databases.

## Acceptance criteria (EARS)

1. While the tool subnets are deployed, the system shall have no route to the virtual private gateway and shall allow outbound HTTPS only to the VPC endpoints.
2. The system shall provide interface endpoints to Athena and logs for the tool subnets.
3. When isolation is probed from the tool side, the system shall show no connection to the on-premises database endpoints.
4. The team shall record whether an AgentCore interface endpoint exists in us-east-1 (Feature List Section 5, gap 8) for use by F10.
