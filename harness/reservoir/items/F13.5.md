# Verify no network path to on-premises databases

Show from the route table and firewall export that no path exists from the assistant to the on-premises databases.

## User story

As a security reviewer, I want route and firewall evidence so that I can confirm the assistant cannot reach on-premises databases.

## Acceptance criteria (EARS)

1. When the route table is exported, the system shall show no route from the assistant's network to the on-premises database networks.
2. When the firewall configuration is exported, the system shall show no rule allowing traffic from the assistant to the on-premises databases.
3. When the exports are reviewed, the system shall save them as evidence with the export date.
