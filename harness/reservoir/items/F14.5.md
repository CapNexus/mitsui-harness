# Prepare the readout deck

Prepare the readout deck with results against each criterion, the run-cost estimate and the next-phase recommendation.

## User story

As Mitsui's decision maker, I want a readout deck, so that I can see what the POC proved and what to do next.

## Acceptance criteria (EARS)

1. The readout deck shall state the result against each POC acceptance criterion, using the F13 test results.
2. The readout deck shall include the AWS run-cost estimate from actual usage.
3. The readout deck shall include a next-phase recommendation that considers Quorum, QLS/LIS, Oracle and geospatial.
4. When a criterion was not met, the deck shall state which criterion and why.
