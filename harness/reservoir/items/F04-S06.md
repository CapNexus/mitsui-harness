# Compare row counts after each load

Check every load against source row counts so a load marked complete after a dropped connection is caught.

## User story

As Venkat (DevOps), I want every load checked against the source row counts, so that a load that DMS marks complete after a dropped connection is caught instead of served to users.

## Acceptance criteria (EARS)

1. When all counts match after a load, the check shall publish LoadSucceeded = 1 and TablesMismatched = 0 and write one ok row per table to wda_meta.load_runs.
2. If any table count differs between the DMS statistics and S3 Tables, then the check shall publish LoadSucceeded = 0 and TablesMismatched equal to the number of mismatched tables, and write a mismatch row for each of them to wda_meta.load_runs.
3. Where the DMS statistics are not sufficient, the check shall run COUNT(*) on the source through the read-only login.
