# Enforce code freeze from Dec 18

Put a code freeze in effect from Dec 18 that allows only fixes for failed tests.

## User story

As the pilot lead, I want a code freeze so that the code under test does not change except to fix failed tests.

## Acceptance criteria (EARS)

1. While the code freeze is in effect from Dec 18, the system shall accept only changes that fix a failed test.
2. If a change is proposed during the freeze and does not reference a failed test, the system shall reject it.
3. When the freeze starts, the system shall record the freeze date and the rule that applies.
