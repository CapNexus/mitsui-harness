# Run the generator on the returned inventory and collect owner decisions

After the DBAs return scripts A1, A3 and A4, generate the real pre-filled list, send it to the data owners, and obtain a complete set of decisions.

## User story

As Venkat (DevOps), I want the data owners to decide on every table in the pre-filled list, so that the list is complete and ready for sign-off.

## Acceptance criteria (EARS)

1. When the DBAs return the A1, A3 and A4 CSVs for all three databases, the team shall save them (metadata only) in evidence/F04/inventory/ and set DEP-08 to resolved in the register.
2. When the returned CSVs are saved, the system shall produce config/approved-tables.yaml by running scripts/prefill-approved-tables.sh against evidence/F04/inventory/.
3. When the data owners return the list, every row shall have a decision of Approved, Approved with masking or Not approved, and scripts/check-approved-tables.sh shall exit 0.
4. If the check fails, the team shall return the named rows to the data owners and re-run the check.
