# Build Lake Formation table grants by Entra group as code

Generate Lake Formation table grants from one access matrix file so that access changes are config changes.

## User story

As Venkat (DevOps), I want Lake Formation table grants generated from one access matrix file, so that changing who sees which table is a config change and the same code works in the sandbox and the POC account.

## Acceptance criteria (EARS)

1. When the code is synthesized from a matrix file, the system shall grant SELECT and describe access on each permitted table to each permitted group.
2. Where identity_mode is propagated, the system shall grant to the Identity Center groups.
3. Where identity_mode is group_fallback, the system shall grant to one IAM role per Entra group named wda-grp-<group>.
4. While the matrix is unsigned, the system shall use a sandbox matrix with dummy tables in the three databases.
