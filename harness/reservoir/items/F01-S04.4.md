# Record the review clock in the RAID log

Record the clock start date and the end date (8 business days later) for D1 in the RAID log.

## User story

As Mike (CapNexus project manager), I want the review clock start and end dates in the RAID log, so that we can plan around the acceptance deadline.

## Acceptance criteria (EARS)

1. When D1 is submitted, the system shall record the review clock start date in the RAID log row for D1.
2. When the start date is recorded, the system shall record the end date as 8 business days later.
3. When `scripts/check-raid-log.sh --require-clock D1` is run and both dates are present, the system shall exit 0.
4. If either date is missing, the system shall exit non-zero.
