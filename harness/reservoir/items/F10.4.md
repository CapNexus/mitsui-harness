# Forward questions with the asker's identity and return a table plus SQL

Pass each question and the asker's identity to the assistant and post back a short table plus the SQL, so answers reflect the asker's permissions.

## User story

As a pilot user, I want my question answered with a table and the SQL, limited to data I may see, so that I can trust and check the result.

## Acceptance criteria (EARS)

1. When an authenticated message arrives, the system shall forward the question and the asker's identity to the assistant.
2. When the assistant returns a result, the system shall reply with a short table and the SQL that produced it.
3. While the asker lacks permission for a table, the system shall exclude that table from the answer.
4. If the assistant returns an error, then the system shall reply with a short error message and no partial restricted data.
