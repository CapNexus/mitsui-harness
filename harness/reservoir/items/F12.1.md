# Encrypted log destinations with restricted read access

Provide the customer-managed-KMS-encrypted log storage that the audit, CloudTrail and Bedrock logs write to, readable only by the people InfoSec named.

## User story

As an InfoSec reviewer, I want audit logs encrypted with the customer-managed KMS key and readable only by named people, so that business data in the logs is protected.

## Acceptance criteria (EARS)

1. When a log destination is created, the system shall encrypt it with the customer-managed KMS key.
2. If a principal not named by InfoSec requests read access to the audit logs, then the system shall deny the request.
3. Where a principal is named by InfoSec, the system shall allow read access to the audit logs and to the KMS key for decryption.
