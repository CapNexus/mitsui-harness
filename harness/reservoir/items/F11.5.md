# Verify group enforcement and permission parity with Teams

Show that users outside `sg-wda-itpmo-tools` are denied from both clients, and that Users A, B and C get the same permission results as in Teams.

## User story

As the IT/PMO lead, I want access limited to the approved group and consistent with Teams so that the new clients do not widen access.

## Acceptance criteria (EARS)

1. If a user outside `sg-wda-itpmo-tools` attempts to use the Gateway tools from Claude Code, the system shall deny the request.
2. If a user outside `sg-wda-itpmo-tools` attempts to use the Gateway tools from Claude Desktop, the system shall deny the request.
3. When Users A, B and C run the same requests from Claude Code, the system shall return the same permission results as in Teams.
4. When Users A, B and C run the same requests from Claude Desktop, the system shall return the same permission results as in Teams.

- F11.4: Verify Claude Desktop sign-in and the four tools with a recorded session
