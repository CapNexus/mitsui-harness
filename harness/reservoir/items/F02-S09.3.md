# Write and run scripts/check-kms-usage.sh

Provide a checker that confirms Secrets Manager secrets and log groups in the POC account use the customer-managed key.

## User story

As Venkat (DevOps), I want a script that checks encryption usage, so that I can prove all secrets and log groups use the customer-managed key.

## Acceptance criteria (EARS)

1. When `scripts/check-kms-usage.sh` is run and every Secrets Manager secret and log group in the account uses the customer-managed key, the system shall exit with code 0.
2. If any Secrets Manager secret or log group does not use the customer-managed key, the system shall exit non-zero and list each non-compliant resource.
3. When the script is run after the pipeline deployment, the system shall have its output saved in evidence/F02/pipeline/.
