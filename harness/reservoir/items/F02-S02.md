# Create the CDK app and pipeline skeleton

Create a CDK app, pipeline skeleton and config file mirroring config/parameters.md so later stacks drop in and Mitsui values change by config.

## User story

As Venkat (DevOps), I want a CDK app with a pipeline skeleton and a config file that mirrors config/parameters.md, so that every later infrastructure story adds a stack in one place and Mitsui values are swapped by config, not code.

## Acceptance criteria (EARS)

1. When the build runs on a clean checkout with placeholder values, dependencies shall install, lint shall pass and cdk synth shall succeed.
2. The config file shall mirror the parameters in config/parameters.md so that a stack reads Mitsui values from config, not from code.
3. The pipeline shall use CDK Pipelines with an AWS CodeConnections source whose connection ARN is a placeholder in the sandbox.
