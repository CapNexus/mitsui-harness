# Spike identity propagation to Athena in the sandbox

Show in the sandbox whether a user's OIDC token can be carried through the trusted token issuer to Athena and Lake Formation.

## User story

As Soma (solution architect), I want to prove in the sandbox that a user's OIDC token can be carried to Athena and Lake Formation, so that we know before Dec 2 whether identity_mode propagated is realistic.

## Acceptance criteria (EARS)

1. When two sandbox users in different groups each run the same SELECT through the identity-aware workgroup with their own token, the system shall show each query under that user's identity in Athena query history or CloudTrail.
2. The spike shall produce a reusable script, scripts/test-identity-propagation.sh, that F06-S07 runs against the POC account.
3. When the spike ends, the team shall have a written findings report for Soma to review.
