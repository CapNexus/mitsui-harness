# Send the Palo Alto configuration to Matt and get his confirmation of receipt

Deliver the generated configuration to Matt Schiefelbein through an agreed secure channel and record that he received it.

## User story

As Venkat (DevOps), I want to send the configuration to Matt securely, so that he can apply it on the Palo Alto and bring up the tunnels.

## Acceptance criteria (EARS)

1. When the configuration file has been generated, the system shall send it to Matt through the agreed secure channel.
2. When Matt confirms receipt, the system shall record the confirmation.
3. While the file is in transit and after delivery, the system shall not store the file or its pre-shared keys in the repository.
