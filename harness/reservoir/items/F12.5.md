# CloudWatch dashboard and latency report

Provide a CloudWatch dashboard of latency, errors and throttling, and a latency report that supports the 60-second claim.

## User story

As an operator, I want a dashboard of latency, errors and throttling, so that I can see service health and show answers come back within 60 seconds.

## Acceptance criteria (EARS)

1. The system shall display latency, errors and throttling on a CloudWatch dashboard.
2. When a latency report is requested for a period, the system shall report latency for that period in a form that shows whether the 60-second claim holds.
