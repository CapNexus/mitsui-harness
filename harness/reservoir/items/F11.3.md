# Verify Claude Code sign-in and the four tools with a recorded session

Show that a member of `sg-wda-itpmo-tools` on a Mitsui-managed laptop can sign in through Entra from Claude Code and use list, describe, sample and SELECT.

## User story

As an IT/PMO user, I want to use the Gateway tools from Claude Code so that I can query data with my own identity.

## Acceptance criteria (EARS)

1. When a member of `sg-wda-itpmo-tools` on a Mitsui-managed laptop adds the Gateway in Claude Code, the system shall sign the user in through Entra with MFA applied.
2. When the signed-in user invokes list, describe, sample and SELECT from Claude Code, the system shall return results for each tool.
3. When the test is run, the system shall produce a recorded session that shows sign-in and all four tool calls.

- F11.2: Setup guide for adding the Gateway in Claude Code and Claude Desktop
