# Orchestrate and schedule the daily load

Run the whole daily load in order from one scheduled Step Functions workflow inside the agreed window.

## User story

As Venkat (DevOps), I want one scheduled workflow that runs the whole daily load in order, so that the load runs every day inside the agreed window with no manual action.

## Acceptance criteria (EARS)

1. When the EventBridge schedule fires at the start of load_window, the state machine shall check SDEDBPROD currency, start the DMS full-load tasks, run the load job, run the row-count check, and call the catalog update hook if the schema changed, in that order.
2. If sdedbprod_mode is undecided or SDEDBPROD is not current, then the state machine shall skip SDEDBPROD and publish the SDEDBPROD-skipped metric.
3. While the date is in load_blackout_dates, the schedule shall not start a run.
4. The state machine shall time out at the length of the window.
5. Until F5 delivers the catalog update hook, the hook shall be a no-op.
