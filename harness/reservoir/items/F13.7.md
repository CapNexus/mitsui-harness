# Unattended daily load evidence, Dec 14 to Dec 25

Show from DMS task and alarm history that the daily load ran unattended from Dec 14 to Dec 25.

## User story

As a Mitsui verifier, I want DMS history for the load window so that I can confirm the load ran without manual help.

## Acceptance criteria (EARS)

1. While the load window runs from Dec 14 to Dec 25, the daily load shall run without manual intervention.
2. When the DMS task and alarm history is exported on Dec 24, the system shall show each daily run from Dec 14 to Dec 24 and its alarms.
3. When the Dec 25 run is added after the holiday, the system shall extend the exported history to include Dec 25.
4. When the history is exported, the system shall save it as evidence.
