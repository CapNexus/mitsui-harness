# Wire the four tools and pass the asking user's token

Connect the assistant to the four tools from F8 and make every tool call carry the asking user's token, never a shared service identity.

## User story

As a data owner, I want the assistant to query data as the person asking, so that existing data permissions apply to every answer.

## Acceptance criteria (EARS)

1. When the assistant calls a tool, the system shall send the asking user's token with the call.
2. If the asking user's token is absent or expired, then the system shall refuse to call the tool and shall tell the user to sign in again.
3. The system shall expose only the four tools to the model and shall reject any call to another tool name.
