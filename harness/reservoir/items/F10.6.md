# Verify pilot users are enrolled in the Entra groups, Team and channel

Confirm in the deployed environment that all 15 pilot users are in the Entra groups, the Team and the pilot channel.

## User story

As a pilot lead, I want proof that every pilot user is enrolled so that the pilot can start.

## Acceptance criteria (EARS)

1. When the enrolment check runs, the system shall report that all 15 pilot users are members of the required Entra groups.
2. When the enrolment check runs, the system shall report that all 15 pilot users are members of the Team and the pilot channel.
3. If any pilot user is missing from a group, the Team or the channel, then the system shall list that user and the missing membership.

- (not grounded)

- Requires DEP-22: pilot users must be named and enrolled.
- User names are personal data; keep them out of logs.
