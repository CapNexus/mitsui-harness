# Build the trusted token issuer and identity-aware Athena workgroup as code

Define the trusted token issuer and the identity-aware Athena workgroup as CDK code driven by parameters so that the Mitsui tenant is a config change.

## User story

As Soma (solution architect), I want the trusted token issuer and identity-aware Athena workgroup defined as CDK code that takes the issuer URL and audience as parameters, so that we can test in the sandbox now and point it at Mitsui's Entra tenant on Dec 1 with a config change only.

## Acceptance criteria (EARS)

1. When the stack is synthesized with sandbox values, the stack shall create a trusted token issuer with the URL from entra_issuer_url and the claim mapping.
2. When the stack is synthesized, the stack shall create an identity-aware Athena workgroup with a per-query scan cutoff of athena_scan_cutoff_gb.
3. When the issuer URL or audience parameter changes, the stack shall change only configuration and not code.
4. The stack shall be addable to the F2 CDK app without changes to the app.
