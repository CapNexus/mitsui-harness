# Generate the Palo Alto configuration for Mitsui's model and PAN-OS version

Provide scripts/get-palo-alto-config.sh, which reads the deployed VPN connection and writes the Palo Alto configuration file without storing pre-shared keys in the repository.

## User story

As Venkat (DevOps), I want the Palo Alto configuration generated from the deployed VPN connection, so that Matt can apply it on Mitsui's firewall.

## Acceptance criteria (EARS)

1. When scripts/get-palo-alto-config.sh runs against the deployed VPN connection, the system shall write a configuration file for Mitsui's Palo Alto model and PAN-OS version and exit 0.
2. While the configuration file contains pre-shared keys, the system shall keep the file and the keys out of the repository.
3. If the VPN connection is not deployed, the system shall exit non-zero without writing a file.

## Scope

- file: `scripts/get-palo-alto-config.sh`

## Depends on

- F03-S05.1: Deploy the network, VPN and endpoint stacks to the POC account through the pipeline

## Ship notes

- The generated file is not stored; evidence records only that the script succeeded.
- Needs Mitsui's Palo Alto model and PAN-OS version from DEP-07.
