# Pre-fill the description sheet and send it to the SMEs

Pre-fill the SME description sheet with table names, column names, types and draft text so SMEs only correct and complete it.

## User story

As a Mitsui SME, I want a description sheet that is already filled in with table names, column names, types and draft text, so that I only correct and complete it instead of starting from a blank page.

## Acceptance criteria (EARS)

1. When scripts/prefill-descriptions.* runs on the approved list or the inventory, it shall write config/descriptions.yaml with database, table, column and data type filled in for every listed table.
2. The script shall mark every drafted description with source: draft.
3. Where the approved list is not signed by Nov 25, the script shall use the inventory.
