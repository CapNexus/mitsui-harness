# Validate both tunnels and TCP reachability from the DMS subnet

Provide a repeatable test that both VPN tunnels are up and each SQL Server port answers from the DMS subnet.

## User story

As Soma (solution architect), I want a repeatable test that shows both tunnels are up and each SQL Server port answers from the DMS subnet, so that DMS setup on Tue Nov 24 starts on a working network.

## Acceptance criteria (EARS)

1. When the VPN status check runs, scripts/check-vpn-tunnels.sh shall exit 0 only when both tunnels report UP.
2. When the probe deployed in the DMS subnet connects to each host and fixed port in sql_server_endpoints, scripts/tcp-probe.sh --subnet dms shall exit 0 and report success for MEPWELL, SDEDBPROD and MEPS_ARIES.
