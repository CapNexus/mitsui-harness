# Write the operations runbook

Give the Mitsui IT operations owner a runbook covering every routine and exceptional operation of the deployed POC.

## User story

As the Mitsui IT operations owner, I want a runbook for the POC, so that I can run, repair and tear down the deployment without CapNexus.

## Acceptance criteria (EARS)

1. When the runbook is delivered, the system shall document the daily load procedure and the alarms an operator must watch, with the action for each alarm.
2. When a load fails, the runbook shall describe the rerun procedure step by step.
3. When a secret or SCIM token nears expiry, the runbook shall describe the secret rotation and SCIM token renewal procedures.
4. The runbook shall document the Region and service-limit settings the deployment depends on.
5. When Mitsui chooses to tear down, the runbook shall describe the teardown procedure, based on the F2 teardown scripts.
