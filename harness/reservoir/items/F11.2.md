# Setup guide for adding the Gateway in Claude Code and Claude Desktop

Document how an IT/PMO user adds the Gateway as an MCP server in each client and signs in through the pre-registered WDA-Clients app.

## User story

As an IT/PMO user, I want step-by-step setup instructions so that I can connect each client without help.

## Acceptance criteria (EARS)

1. When a user follows the guide for Claude Code, the system shall show the Gateway as a configured MCP server.
2. When a user follows the guide for Claude Desktop, the system shall show the Gateway as a configured MCP server.
3. The guide shall state that sign-in uses the pre-registered WDA-Clients app because Entra has no dynamic client registration.
4. The guide shall list the required group, `sg-wda-itpmo-tools`, and the Mitsui-managed laptop requirement.
