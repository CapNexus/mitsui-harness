Produce the D1 draft (confirmed project plan and question set outline) for Mike to review.

## User story

As Mike (CapNexus project manager), I want the agent to draft D1 from the task list and Feature List, so that I only have to review it rather than write it.

## Acceptance criteria (EARS)

1. When the agent drafts D1 from `task-list/` and the Feature List, the system shall produce a draft containing the project plan with dates.
2. When the agent drafts D1, the system shall include the dependency owners in the draft.
3. When the agent drafts D1, the system shall include a question set outline with about 7 questions per database and 9 joins.
4. When the draft is complete, the system shall pass `scripts/check-d1-draft.sh`.
