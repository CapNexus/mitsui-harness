# Verify write attempts are refused from both clients

Show that a write attempt from Claude Code and from Claude Desktop is refused, so the Gateway stays read-only for these clients.

## User story

As the IT/PMO lead, I want write attempts refused so that the clients cannot change data.

## Acceptance criteria (EARS)

1. If a signed-in authorized user submits a write statement from Claude Code, the system shall refuse it and leave the data unchanged.
2. If a signed-in authorized user submits a write statement from Claude Desktop, the system shall refuse it and leave the data unchanged.

## Scope

- (not grounded)

## Depends on

- F11.3: Verify Claude Code sign-in and the four tools with a recorded session
- F11.4: Verify Claude Desktop sign-in and the four tools with a recorded session

## Ship notes

- Run against a non-production target, or against a table where an unintended write would be harmless.
