# Create and authorize the CodeConnections connection to Mitsui's repository

Establish an AVAILABLE AWS CodeConnections connection to Mitsui's Git host so a push to main starts the pipeline.

## User story

As Venkat (DevOps), I want the pipeline connected to Mitsui's repository, so that pushes to main trigger deployments from code.

## Acceptance criteria (EARS)

1. When the CodeConnections connection to Mitsui's repository is created and a Mitsui Git administrator authorizes the connection app, the system shall report the connection status as AVAILABLE.
2. When a commit is pushed to the main branch of the repository, the system shall start a pipeline execution for that commit.
3. When the connection is verified, the system shall have the get-connection output and the pipeline execution history entry saved in evidence/F02/pipeline/.
