# Acceptance test: audit records for 20 sampled questions

Show that for 20 sampled pilot questions the audit records are complete and gap-free.

## User story

As a pilot sponsor, I want a test that checks 20 sampled questions for complete audit records, so that I can trust the audit trail.

## Acceptance criteria (EARS)

1. When 20 pilot questions are sampled, the test shall find an audit record for each showing user, question, tool calls, SQL, timestamp and row count.
2. If any sampled question has a missing record or missing field, then the test shall fail and name the question and field.
3. The test shall confirm that CloudTrail and Bedrock invocation log entries exist for each sampled question.
