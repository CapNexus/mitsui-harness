# Build sandbox source databases with synthetic data

Create a SQL Server 2017 sandbox with synthetic MEPWELL, SDEDBPROD and MEPS_ARIES databases so the load pipeline can be built before Mitsui access exists.

## User story

As Venkat (DevOps), I want a sandbox SQL Server with synthetic MEPWELL, SDEDBPROD and MEPS_ARIES databases, so that the whole load pipeline can be built and tested before Mitsui's network and logins are ready.

## Acceptance criteria (EARS)

1. When make sandbox-up and make sandbox-test run, the sandbox shall hold the three databases with mixed-case table and column names, and a cross-database join through the crosswalk shall return at least one row.
2. The sandbox shall include a versioned feature class with an _evw view and a geometry column, a table with a sql_variant column, and one shape value above the LOB cap.
3. The sandbox shall produce inventory CSVs in the same format as scripts A3 and A4.
4. The sandbox shall provide a read-only login as defined in Appendix A2.
