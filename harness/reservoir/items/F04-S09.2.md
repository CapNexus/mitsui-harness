# Replace placeholders with real endpoints, approved table list and secrets

Swap the placeholder values for sql_server_endpoints, the signed approved_table_list and the three DMS secrets (secret_dms_mepwell, secret_dms_sdedbprod, secret_dms_meps_aries). A human enters the credentials in Secrets Manager; the harness never sees them.

## User story

As Venkat (DevOps), I want the real endpoint values, signed table list and secrets in place, so that DMS can connect to the three Mitsui SQL Servers.

## Acceptance criteria (EARS)

1. When the real SQL Server endpoint values are supplied, the system shall use them in place of the sql_server_endpoints placeholders in the deployed configuration.
2. When the signed approved table list is supplied, the system shall use it as the approved_table_list in config/approved-tables.yaml.
3. When a human enters the three secret values from the DBAs' secure channel, the system shall hold them only in Secrets Manager.
4. The system shall not expose the credential values to the harness, its logs or the evidence files.
