# Partial-load and error alarms with SNS email

Create CloudWatch alarms for partial load and errors that notify the Mitsui distribution list by SNS email.

## User story

As an operator, I want alarms for partial loads and errors sent by email to the Mitsui distribution list, so that problems are noticed quickly.

## Acceptance criteria (EARS)

1. When a partial load is detected, the system shall raise an alarm.
2. When the error rate exceeds the alarm threshold, the system shall raise an alarm.
3. When an alarm is raised, the system shall publish a message to an SNS topic that emails every subscriber on the Mitsui distribution list.
