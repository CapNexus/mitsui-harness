# Build the column-masking data filter as code

Enforce the masked column with a Lake Formation data filter so that only sg-wda-econ-sensitive sees the real value.

## User story

As Venkat (DevOps), I want the masked column enforced by a Lake Formation data filter driven by the matrix file, so that only sg-wda-econ-sensitive sees the real value and swapping in Mitsui's column is a config change.

## Acceptance criteria (EARS)

1. When the stack is synthesized with masked_column in the matrix, the system shall create a data filter on that table that includes all columns except the masked one.
2. When the stack is synthesized, the system shall grant the data filter to every permitted group except sg-wda-econ-sensitive.
3. When the stack is synthesized, the system shall grant the full table to sg-wda-econ-sensitive.
