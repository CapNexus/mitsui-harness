# Record the DBA-confirmed load window and blackout dates

Capture the load window and blackout dates the DBAs confirm in writing, set them in config/parameters.md, and log the source in the RAID log.

## User story

As Noah Jackson (Mitsui), I want the load window and blackout dates recorded from our DBAs' written answer, so that the schedule uses values we agreed to.

## Acceptance criteria (EARS)

1. When the DBAs' written confirmation of the load window and blackout dates is received, the system shall hold `load_window` and `load_blackout_dates` in `config/parameters.md` with status `set`.
2. When the parameters are set, the system shall record the source of the values (the DBA confirmation) in the RAID log.
3. When `scripts/check-raid-log.sh` is run after the values are recorded, the system shall exit with code 0.
4. If the DBA confirmation has not been received, the system shall keep both parameters unset and shall not mark this item complete.
