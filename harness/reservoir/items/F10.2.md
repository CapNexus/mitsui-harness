# Expose the bot messaging endpoint behind AWS WAF

Publish the `/api/messages` endpoint behind AWS WAF and set it as the Azure Bot's messaging endpoint.

## User story

As a security reviewer, I want the bot endpoint to sit behind AWS WAF so that internet traffic is filtered before it reaches the service.

## Acceptance criteria (EARS)

1. When a request is sent to `/api/messages`, the system shall route it through the AWS WAF web ACL.
2. When the endpoint is deployed, the system shall serve `/api/messages` over HTTPS only.
3. When the Azure Bot is configured, the system shall use the deployed endpoint URL as its messaging endpoint.
