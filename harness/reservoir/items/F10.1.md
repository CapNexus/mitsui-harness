# Provision the single-tenant Azure Bot resource

Create the Azure Bot resource (single tenant) in a Mitsui Azure subscription so Teams and Web Chat have a bot identity to talk to.

## User story

As a pilot administrator, I want an Azure Bot registered in Mitsui's Azure subscription so that Teams can route messages to our assistant.

## Acceptance criteria (EARS)

1. When the Azure Bot resource is created, the system shall be registered as a single-tenant bot in a Mitsui Azure subscription.
2. When the bot registration is complete, the system shall have the Teams and Web Chat channels enabled.
3. When the bot app credentials are issued, the system shall store them in a secrets store and not in source control.
