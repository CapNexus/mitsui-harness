# Runbook entry for log retention

Record in the runbook that log retention uses AWS defaults.

## User story

As an operator, I want the runbook to state the log retention settings, so that nobody assumes a custom retention period.

## Acceptance criteria (EARS)

1. The runbook shall state that audit, CloudTrail and Bedrock invocation logs use AWS default retention.
2. The runbook shall list where each log type is stored and which account holds it.
