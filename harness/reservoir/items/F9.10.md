# Verify in the audit log that tools ran as the asking user

Check the deployed environment's audit log to confirm each tool call was made with the asking user's identity.

## User story

As an auditor, I want evidence that queries ran as the asking user, so that access can be traced to a person.

## Acceptance criteria (EARS)

1. When a test user asks a question, the system shall record the tool calls in the audit log under that user's identity.
2. If an audit log entry shows a shared service identity for a tool call, then the check shall fail.
3. When the check passes, the system shall write the matching log entries to the test report.
