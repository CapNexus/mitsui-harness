# Create the load-evidence export script

Create scripts/export-load-evidence.sh, which saves the DMS task history, Step Functions executions, load_runs and alarm history for a date range and fails if any execution was started manually.

## User story

As Noah Jackson (Mitsui), I want a repeatable export of the load history, so that the evidence for the unattended window can be produced the same way every time.

## Acceptance criteria (EARS)

1. When scripts/export-load-evidence.sh is run with --from and --to dates, the system shall write the DMS task history, Step Functions executions, load_runs and alarm history for that range to files.
2. If any execution in the range was started manually, the script shall exit non-zero and name the execution.
3. When no execution in the range was started manually, the script shall exit zero.

## Scope

- (not grounded)

## Ship notes

- The script is created by this story at scripts/export-load-evidence.sh.
- Reads the load window and blackout dates (params load_window, load_blackout_dates) from the values set in F04-S11 (DEP-12).
- Needs read access to DMS, Step Functions, the load_runs table and CloudWatch alarm history.
