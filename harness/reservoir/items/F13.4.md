# Permission tests for Users A, B and C across three clients

Prove that Users A, B and C get the results in the expected permissions table through Teams, Claude Code and Claude Desktop.

## User story

As a Mitsui verifier, I want each user's results checked per client so that data access follows each user's permissions.

## Acceptance criteria (EARS)

1. When User A, B or C asks the test questions through Teams, the system shall return results matching the expected table.
2. When User A, B or C asks the test questions through Claude Code, the system shall return results matching the expected table.
3. When User A, B or C asks the test questions through Claude Desktop, the system shall return results matching the expected table.
4. When the tests finish, the system shall save the actual results next to the expected table.
