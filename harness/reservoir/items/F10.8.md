# Measure answer latency on the frozen question set and report it

Run the frozen question set through the bot and show median and p90 latency in the dashboard report, against the 60-second target.

## User story

As a pilot lead, I want latency measured on a fixed question set so that I can confirm typical answers arrive within 60 seconds.

## Acceptance criteria (EARS)

1. When the frozen question set is run, the system shall record the end-to-end latency of each answer.
2. When the run completes, the system shall report the median and p90 latency in the dashboard report.
3. If the median or p90 latency is 60 seconds or more, then the system shall mark the latency check as failed.
