# Enforce SELECT-only, row limits and timeouts with AgentCore Policy

Configure AgentCore Policy to allow only the four approved tools, only single SELECT statements and only within the agreed limits, so write attempts are refused at the first layer and logged.

## User story

As Soma (solution architect), I want AgentCore Policy to allow only the four approved tools, only single SELECT statements, and only within the agreed limits, so that write attempts are refused at the first layer and logged.

## Acceptance criteria (EARS)

1. When the policy code is synthesized, the system shall allow only list_tables, describe_columns, sample_rows and run_select, with limit and timeout values taken from the parameters (verify: make test-policy passes).
2. If a request contains a write statement such as INSERT or UPDATE, then the system shall refuse it and write the refusal to the log.
3. If a rule cannot be expressed in AgentCore Policy, then the system shall enforce it in the tool (F08-S02) and the gap shall be recorded.
