# Attach Bedrock Guardrails to the assistant

Create a Bedrock Guardrail, including prompt-attack filtering, and attach it to every model call the assistant makes.

## User story

As a security reviewer, I want Bedrock Guardrails on every model call, so that hostile text in prompts or data is filtered.

## Acceptance criteria (EARS)

1. When the assistant calls Claude on Bedrock, the system shall include the configured Guardrail identifier and version on the call.
2. Where the Guardrail prompt-attack filter is enabled, the system shall apply it to user input and to tool results passed back to the model.
3. If the Guardrail identifier is missing from the deployed configuration, then the deployment check shall fail.
