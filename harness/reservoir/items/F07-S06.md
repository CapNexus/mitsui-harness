# Create test users A, B, C and run the first permission test

Create the three Mitsui test users in the right groups and run the first permission test through Athena and the Gateway.

## User story

As Soma (solution architect), I want the three Mitsui test users created in the right groups and the first permission test run through Athena and the Gateway, so that we find access-control gaps in Week 3, not in UAT.

## Acceptance criteria (EARS)

1. When the Entra administrator creates the test users, User A shall be in all permitted groups and sg-wda-econ-sensitive, User B shall be in permitted groups but not sg-wda-econ-sensitive, and User C shall be in no group.
2. When the users are created, all three shall appear in Identity Center.
3. When the permission test runs through Athena, the system shall produce a report in user-stories/evidence/F07/.
4. While F8 is not deployed in the POC account, the test shall run the Athena entry point only and log the gap.
