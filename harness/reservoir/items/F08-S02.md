# Build the four read-only tool Lambdas

Implement the four MCP tools (list_tables, describe_columns, sample_rows, run_select) as Lambdas over Athena so clients can discover and read data and do nothing else.

## User story

As Soma (solution architect), I want four small Lambda functions that implement the tool contract against Athena, so that the assistant and the Claude clients can discover tables, read descriptions, sample values and run SELECT queries, and nothing else.

## Acceptance criteria (EARS)

1. The system shall provide one Lambda per tool for list_tables, describe_columns, sample_rows and run_select, matching the tool contract from F08-S01.
2. When a tool returns table or column descriptions, the system shall read them from the Glue Data Catalog and, until SME descriptions arrive, from the placeholder descriptions in sme_descriptions_file.
3. If a submitted statement is not a single SELECT or contains a write keyword, then the system shall refuse it before it reaches Athena.
4. While running in the sandbox, the system shall pass its tests against dummy tables in the three databases and the sandbox OIDC provider.
5. Where identity_mode is propagated or fallback, the system shall run correctly in both modes.
