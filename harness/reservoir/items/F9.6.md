# Answer format: short table plus the SQL that ran

Define the answer format so every answer shows a short result table and the exact SQL that was executed.

## User story

As a well data analyst, I want to see the SQL behind each answer, so that I can check it.

## Acceptance criteria (EARS)

1. When a query succeeds, the system shall return a short table of the results.
2. When a query succeeds, the system shall include the exact SQL that ran in the answer.
3. If a result has more rows than the display limit, then the system shall show the first rows and state the total row count.
