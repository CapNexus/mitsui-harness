# Acceptance tests: Web Chat, pilot channel and permissions

Prove end to end that Web Chat and the pilot channel return a table plus SQL, and that restricted tables stay hidden from User C.

## User story

As a pilot lead, I want end-to-end tests of the bot so that I can sign off the functional behavior.

## Acceptance criteria (EARS)

1. When a test question is sent in Web Chat, the system shall return an answer.
2. When a Mitsui test user asks a question in the pilot channel after the app is installed, the system shall reply with a table plus SQL.
3. When User C asks a question that touches restricted tables, the system shall return no restricted tables.
4. When a POST to `/api/messages` has an invalid or missing Bot Framework JWT, the system shall reject it before it reaches the assistant.
5. When all 15 pilot users have been enrolled, the system shall show that each completed at least one question.
