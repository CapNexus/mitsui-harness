# Deploy the baseline stacks through the pipeline and confirm a second run is a no-op

Prove the KMS, logging and budget stacks deploy into an empty POC account from the pipeline with no manual step and are idempotent.

## User story

As Venkat (DevOps), I want the pipeline to deploy the baseline into the POC account, so that every POC resource comes from code and nothing is clicked in the console.

## Acceptance criteria (EARS)

1. When the pipeline runs against an empty POC account, the system shall deploy the KMS, logging and budget stacks with no manual step.
2. When the pipeline runs a second time with no code change, the system shall make no changes to the account.
3. When `cdk diff` is run against the POC account after the run, the system shall report no difference.
4. When the deployment completes, the system shall have the pipeline run link and the `cdk diff` output saved in evidence/F02/pipeline/.
