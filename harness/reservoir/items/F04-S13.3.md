# Create the load-freeze check script and the freeze tag

Create scripts/check-load-freeze.sh and the freeze tag on Dec 14, so any deploy of the load pipeline after the freeze must be linked to a failed-load issue in the RAID log.

## User story

As Noah Jackson (Mitsui), I want proof that the load pipeline was frozen from Dec 14 except for failed-load fixes, so that I know the clean runs reflect an unchanged pipeline.

## Acceptance criteria (EARS)

1. When the freeze starts on Dec 14, the system shall have a freeze tag in the code repository.
2. When scripts/check-load-freeze.sh is run with --since 2026-12-14, the system shall list every deploy of the load pipeline after the tag.
3. If a deploy after the freeze tag is not linked to a RAID issue ID for a failed load, the script shall exit non-zero.
4. When the script is run, the system shall save its output under evidence/F04/unattended-window/.
