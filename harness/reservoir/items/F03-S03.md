# Build the site-to-site VPN to the Palo Alto

Define the AWS side of the VPN in code so it deploys as soon as the Palo Alto values arrive.

## User story

As Venkat (DevOps), I want the virtual private gateway, customer gateway and VPN connection defined in code, so that the AWS side of the VPN is ready to deploy as soon as Matt sends the Palo Alto values.

## Acceptance criteria (EARS)

1. When the network stack is synthesized, it shall contain a virtual private gateway attached to the VPC, a customer gateway at palo_alto_public_ip, and one VPN connection.
2. Where palo_alto_routing_type is static, the stack shall create a static route for each entry in onprem_cidrs and enable route propagation only for the DMS route table.
3. Where palo_alto_routing_type is bgp, the customer gateway shall use the BGP ASN and the stack shall create no static routes.
