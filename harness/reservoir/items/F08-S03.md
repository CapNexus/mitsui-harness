# Publish the tools through AgentCore Gateway with a JWT authorizer

Register the four tool Lambdas as targets of an AgentCore Gateway that accepts only tokens for the WDA-API audience, so every MCP client must present a valid signed-in user token.

## User story

As Soma (solution architect), I want the four tool Lambdas registered as targets of an AgentCore Gateway that only accepts tokens for the WDA-API audience, so that every MCP client must present a valid signed-in user token.

## Acceptance criteria (EARS)

1. When the Gateway code is synthesized, the system shall define four Lambda targets named as in the tool contract and a JWT authorizer using entra_issuer_url and wda_api_audience (verify: make test-gateway passes).
2. When an MCP client lists tools on the sandbox Gateway with a valid token, the system shall list exactly the four tools (verify: scripts/test-gateway.sh --env sandbox --case list-tools exits 0).
