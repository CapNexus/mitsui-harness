# Build the PrivateLink endpoints

Define interface endpoints and an S3 gateway endpoint in CDK so tools, assistant and DMS reach AWS services without an internet path.

## User story

As Venkat (DevOps), I want interface endpoints for Bedrock, Athena and logging, and an S3 gateway endpoint, so that the tools, assistant and DMS reach AWS services without any internet path.

## Acceptance criteria (EARS)

1. When the endpoint stack is synthesized, the stack shall contain interface endpoints for Bedrock runtime, Athena, CloudWatch Logs and Secrets Manager with private DNS enabled, and an S3 gateway endpoint on the DMS route table.
2. The endpoint security group shall allow inbound TCP 443 only from the VPC's own subnets.
3. When a service is added to the endpoint list in config, the stack shall create an additional endpoint with no code change.
