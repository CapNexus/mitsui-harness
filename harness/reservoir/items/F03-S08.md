# Prove Bedrock, Athena and logs work over PrivateLink with no internet

Run a Lambda in the tool subnet that shows Bedrock, Athena and CloudWatch Logs are reachable over private endpoints only.

## User story

As Venkat (DevOps), I want a test that calls Bedrock, Athena and CloudWatch Logs from inside the VPC with no internet route, so that we know the assistant and tools will work over private endpoints only.

## Acceptance criteria (EARS)

1. When the test resolves the Bedrock runtime, Athena and Logs hostnames in the tool subnet, each shall resolve to a private IP inside vpc_cidr, as checked by scripts/privatelink-check.sh --dns.
2. When the test calls Claude on Bedrock, runs SELECT 1 on Athena and writes a log event from the tool subnet, all three calls shall succeed, as checked by scripts/privatelink-check.sh --calls.
