# Acceptance tests: plain-English and cross-database questions

Test that a plain-English question returns a table and SQL, and that a cross-database question returns the SME-expected result.

## User story

As a product owner, I want SME-checked test questions, so that I know the assistant gives correct answers.

## Acceptance criteria (EARS)

1. When the test asks a plain-English question, the system shall return a short table and the SQL that ran.
2. When the test asks a question spanning at least two of the three databases, the system shall return the result the SME recorded as expected.
3. If the result differs from the SME-expected result, then the test shall fail and shall show both results.
