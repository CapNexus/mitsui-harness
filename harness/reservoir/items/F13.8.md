# Run the pilot with about 15 users and log wrong answers

Run the pilot so that each of about 15 users asks at least five questions and wrong answers are logged with a severity.

## User story

As the pilot lead, I want each pilot user to use the assistant and report wrong answers so that real-use quality is recorded.

## Acceptance criteria (EARS)

1. When the pilot runs, each pilot user shall have asked at least five questions.
2. If a pilot user reports a wrong answer, the system shall log it with a severity.
3. When the pilot ends, the system shall save a per-user question count and the wrong-answer log as evidence.
