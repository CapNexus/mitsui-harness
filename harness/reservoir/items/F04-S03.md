# Generate DMS table mappings from the approved list

Generate DMS table-mapping JSON from config/approved-tables.yaml so DMS copies only approved tables, lowercases names and reads SDEDBPROD as decided.

## User story

As Venkat (DevOps), I want the DMS table mappings generated from the approved table list, so that DMS copies only approved tables, names them in lowercase, and reads SDEDBPROD the way Mitsui decides.

## Acceptance criteria (EARS)

1. When the generator runs, it shall include only rows with decision Approved or Approved with masking, selected by explicit table name and never by wildcard.
2. The generated mappings shall include transformation rules that lowercase schema, table and column names.
3. Where sdedbprod_mode is compress_state0, the generator shall select base tables; where it is evw_views, it shall select the _evw views; where it is undecided, it shall leave SDEDBPROD out of the task.
4. The generated task settings shall use limited-LOB mode with a size cap of 64 KB until a different cap is provided.
