# Build the Teams app package and install it in the pilot channel

Produce the Teams app manifest and package for the bot and get it installed in one pilot channel.

## User story

As a pilot user, I want the bot available in the pilot channel so that I can ask questions where my team works.

## Acceptance criteria (EARS)

1. When the Teams app package is generated, the system shall reference the single-tenant bot's app id in its manifest.
2. When the package is generated, the system shall declare channel scope only for team channels.
3. When a Teams admin has approved the app, the system shall be installed in the pilot channel.
