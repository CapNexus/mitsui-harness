# Question-set accuracy evaluation

Run the frozen 30-question set, have Mitsui SMEs score it with the agreed tolerance, and show at least 80% correct.

## User story

As a Mitsui SME, I want the frozen question set scored against the assistant so that accuracy is judged on questions the build was not tuned on.

## Acceptance criteria (EARS)

1. When the frozen question set is run, the system shall record an answer for each of the 30 questions for SME scoring.
2. When Mitsui SMEs score the answers using the agreed tolerance, the system shall show at least 24 of 30 answers correct.
3. The evaluation shall include about 10 held-back questions that were not used for tuning.
4. When scoring is complete, the system shall save the answers and scores as evidence.
