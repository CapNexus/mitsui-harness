# Generate the pre-filled approved table list from inventory CSVs

Turn the DBA inventory CSVs (A1, A3, A4) into a pre-filled config/approved-tables.yaml and flag columns and table types the copy cannot support.

## User story

As Venkat (DevOps), I want a script that pre-fills the approved table list from the inventory CSVs and marks unsupported tables, so that the data owners only have to make decisions.

## Acceptance criteria (EARS)

1. When scripts/prefill-approved-tables.sh runs with --inventory pointing at the returned inventory CSVs for the three databases, the system shall write config/approved-tables.yaml with one entry per inventory table holding database, schema, table, row count, size and an empty decision field.
2. When the script runs with --dry-run, the system shall print one row per inventory table and shall not write config/approved-tables.yaml.
3. When the A4 column report shows a table with a sql_variant or sparse column, or reports it as temporal or memory-optimized, the system shall mark that table unsupported and record the reason.
4. While the masking decision (F7, DEP-16) is open, the system shall leave the Allowed groups column empty.
5. When the script test runs with a sample CSV that includes one sql_variant table, the system shall pass only if that table is marked unsupported.
