# InfoSec written approval of the connection method

Obtain InfoSec's written approval of the Claude Code and Claude Desktop connection method, including acceptance that returned rows reach the Claude client and its model provider.

## User story

As the IT/PMO lead, I want InfoSec to approve the connection method in writing so that users can connect without breaking security policy.

## Acceptance criteria (EARS)

1. When the connection method is submitted to InfoSec, the system shall have a written approval on file that names the connection method for both Claude Code and Claude Desktop.
2. Where returned rows reach the Claude client and its model provider, the written approval shall state that InfoSec accepts this data flow.
3. If Claude Desktop calls from Anthropic's cloud, the approval shall state that InfoSec accepts an internet-reachable Gateway protected by the JWT authorizer.
