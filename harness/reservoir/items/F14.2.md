# Hand over code, IaC and configuration in the agreed repository

Place the code, IaC, pipeline and configuration in the repository home agreed with Mitsui and prove a Mitsui engineer can deploy from it.

## User story

As a Mitsui engineer, I want the IaC and pipeline in our agreed repository, so that I can deploy the POC myself.

## Acceptance criteria (EARS)

1. When handover starts, the system shall hold the code, IaC, pipeline and configuration in the repository home agreed in DEP-25.
2. When a Mitsui engineer follows the repository instructions, the system shall deploy successfully from that repository.
3. The repository shall contain no secret values and no CapNexus-only credentials.
4. If the deployment from the repository fails, the system shall record the failure and its cause in the handover notes.

- (not grounded)

## Ship notes

- Check that configuration handed over carries no secrets.
