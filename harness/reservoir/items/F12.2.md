# CloudTrail coverage of Athena, Lake Formation and DMS activity

Capture Athena, Lake Formation and DMS API activity in CloudTrail and store it in the Log Archive account.

## User story

As an auditor, I want API activity for Athena, Lake Formation and DMS recorded centrally, so that data access can be traced independently of the application.

## Acceptance criteria (EARS)

1. When an Athena, Lake Formation or DMS API call is made, the system shall record it in CloudTrail.
2. While CloudTrail is enabled, the system shall store the trail logs in the Log Archive account.
3. The system shall encrypt the CloudTrail logs with the customer-managed KMS key.
