# Collect the network values and change tickets from Mitsui

Record every Appendix C network value as a parameter so VPC and VPN code can switch from placeholders to real values by config.

## User story

As Mike (project manager), I want every network value from the Appendix C sheet recorded as a parameter, so that the VPC and VPN code can switch from placeholders to real values with a config change.

## Acceptance criteria (EARS)

1. When Matt Schiefelbein returns the Appendix C sheet, it shall contain the Palo Alto model and PAN-OS version, public IP, routing type (and ASN for BGP), VPC CIDR, on-prem CIDRs (SQL Server subnets only), and the IP, instance and fixed port of each SQL Server, saved in evidence/F03/appendix-c.md.
2. When the sheet is returned, the values shall be recorded in config/parameters.md in place of the TBD entries.
3. When Mitsui confirms CAB ticket numbers for VPN, firewall and SQL changes, the ticket numbers and the DEP-04 change-freeze dates shall be recorded in the RAID log.
