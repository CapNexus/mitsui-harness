# Test identity propagation in the POC account and decide the identity mode

Run the propagation test in the POC account and set identity_mode so that F7 and F8 enforce permissions in the agreed way.

## User story

As Soma (solution architect), I want to run the identity propagation test in the POC account and set the identity mode, so that F7 and F8 enforce permissions the agreed way and every question traces to a named user.

## Acceptance criteria (EARS)

1. When the F06-S06 script runs against the POC account with a Mitsui test user, the system shall produce a test report showing whether queries run under the signed-in user's identity.
2. When the test result is known, Soma shall set identity_mode to propagated or group_fallback and record the decision in the RAID log.
3. If identity_mode is group_fallback, then the system shall log the user's identity at the application layer.
4. If the fallback is used, then Noah Jackson shall accept it in writing by Fri Dec 4.
