# Deploy the assistant on AgentCore Runtime with Claude on Bedrock

Stand up the AgentCore Runtime service that hosts the assistant and invokes Claude on Bedrock, as the base the other children build on.

## User story

As a well data analyst, I want an assistant hosted on AgentCore Runtime that can call Claude, so that I can ask questions about well data in plain English.

## Acceptance criteria (EARS)

1. When a plain-English message is sent to the AgentCore Runtime endpoint, the system shall return a model-generated response from Claude on Bedrock.
2. When the stack is deployed, the system shall create the AgentCore Runtime resources from infrastructure code with no manual console steps.
3. If the Claude model access is not approved in the account, then the deployment check shall fail with a message naming the missing approval.
