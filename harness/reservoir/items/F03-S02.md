# Build the workload VPC with isolated DMS and tool subnets

Define a workload VPC where only the DMS subnets route to the data center so the assistant and tools have no network path to Mitsui's databases.

## User story

As Venkat (DevOps), I want a workload VPC where only the DMS subnets have a route to the data center, so that the assistant and tools have no network path to Mitsui's databases by design.

## Acceptance criteria (EARS)

1. When the network stack is synthesized with vpc_cidr, it shall create the VPC with DMS, tool and endpoint subnets inside that CIDR, and the DMS subnets shall span two Availability Zones.
2. While route tables are evaluated, only the DMS route table shall hold routes to onprem_cidrs, and the tool and endpoint route tables shall have no route to them.
3. The VPC shall have no internet gateway and no NAT gateway.
