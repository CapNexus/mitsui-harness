# Publish Week 6 test plan and written rejection path

Publish the Week 6 test plan that maps each acceptance criterion to a test, a tester and a verifier, together with the written path for rejecting a criterion.

## User story

As the pilot lead, I want a published test plan and rejection path so that testers and Mitsui verifiers know how each criterion is proven or rejected.

## Acceptance criteria (EARS)

1. When the Week 6 test plan is published, the system shall list every acceptance criterion from item 9.4 with a named tester and a named Mitsui verifier.
2. When the Week 6 test plan is published, the system shall state the test method and the expected evidence for each acceptance criterion.
3. If a verifier rejects a criterion, the published rejection path shall require a written rejection reason.
