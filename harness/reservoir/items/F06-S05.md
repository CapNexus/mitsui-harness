# Deploy the trusted token issuer for the Mitsui Entra tenant

Point the trusted token issuer at Mitsui's Entra tenant so that WDA-API tokens are accepted and the user identity can reach Athena.

## User story

As Soma (solution architect), I want the trusted token issuer pointed at Mitsui's Entra tenant, so that tokens issued for WDA-API are accepted and the signed-in user can be carried to Athena.

## Acceptance criteria (EARS)

1. When the pipeline deploys with the real values in config/parameters.md, the trusted token issuer shall use the Mitsui tenant issuer URL and map the email claim.
2. When a Mitsui test user obtains a token for the WDA-API audience, the token exchange with the trusted token issuer shall succeed.
