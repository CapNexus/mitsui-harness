# Show four consecutive clean scheduled loads and export the evidence

On Fri 2026-12-04, run the clean-load-streak check over the scheduled runs and export the schedule and load_runs evidence for Dec 1 to Dec 4.

## User story

As Noah Jackson (Mitsui), I want proof of four clean consecutive scheduled loads, so that I can accept that the daily load runs unattended.

## Acceptance criteria (EARS)

1. When `scripts/clean-load-streak --as-of 2026-12-04` is run, the system shall print a value of 4 or more.
2. When the streak is computed, the system shall count only runs started by the schedule with no manual start.
3. When the evidence is exported, the system shall store the schedule output and the `load_runs` export for Dec 1 to Dec 4 under `evidence/F04/schedule/`.
4. If the streak is below 4, the system shall report the shortfall and shall not mark this item complete.
