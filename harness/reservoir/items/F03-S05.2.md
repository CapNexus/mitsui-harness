# Verify the POC deployment is idempotent with a second run

Show that a second pipeline run changes nothing and that cdk diff against the POC account is empty.

## User story

As Venkat (DevOps), I want proof that a repeat deployment makes no changes, so that the deployed state is known to match the code.

## Acceptance criteria (EARS)

1. When the pipeline runs a second time after the first successful deployment, the system shall make no changes to the network, VPN and endpoint stacks.
2. When cdk diff runs against the POC account after the second run, the system shall report no difference.
3. When the check completes, the system shall save the cdk diff output in evidence/F03/deploy/.
