# Detect schema changes after each load

Compare loaded table schemas with the catalog after every load so that changes update the catalog or raise an alarm and the assistant never reads stale columns.

## User story

As Venkat (DevOps), I want the catalog checked against the loaded tables after every load, so that a source schema change either updates the catalog or raises an alarm.

## Acceptance criteria (EARS)

1. When a loaded table has a new column, the step shall register the column with the comment "DRAFT: no SME description yet" and add it to the missing_descriptions list.
2. When a loaded table has a removed or retyped column, the step shall update the catalog and keep the old description in a change log.
3. When any schema change is found, the step shall publish a SchemaChanged metric with the table name.
4. When the SchemaChanged metric is published, the alarm on it shall notify the SNS topic from F04-S07.
