# Deploy the network, VPN and endpoint stacks to the POC account through the pipeline

Run the F2 pipeline with Mitsui's real network values so the network, VPN and endpoint stacks exist in the POC account, with the run link and cdk diff saved as evidence.

## User story

As Venkat (DevOps), I want the VPC, VPN and endpoints deployed through the pipeline with Mitsui's real values, so that Matt can configure the Palo Alto and bring the tunnels up.

## Acceptance criteria (EARS)

1. When the pipeline runs with the real values for vpc_cidr, onprem_cidrs, palo_alto_public_ip and palo_alto_routing_type, the system shall deploy the network, VPN and endpoint stacks to the POC account.
2. When the deployment finishes, the system shall store the pipeline run link and the cdk diff output in evidence/F03/deploy/.
3. If any of the four real network values is missing, the system shall stop the pipeline run without deploying.
