# Stop the DMS task mid-load on a manual run and capture the alarm transition

Show that a partial load is detected: the partial-load alarm moves to ALARM and the notification is published to alarm_distribution_list (E2E-6). Run outside the load window, on a manual run, before Dec 11.

## User story

As a Mitsui DBA, I want a deliberately broken load to trigger the partial-load alarm, so that I know a real failure would be reported.

## Acceptance criteria (EARS)

1. When a manual load run in the POC account has its DMS task stopped mid-load, the system shall move the partial-load alarm to ALARM.
2. When the partial-load alarm enters ALARM, the system shall send an email to the address in alarm_distribution_list.
3. When the fault test completes, the system shall have its `aws cloudwatch describe-alarm-history` output showing the transition saved under `evidence/F04/fault-test/`.
