# Prove Lake Formation refuses writes sent directly to Athena

Show with an automated test that Lake Formation refuses write statements even if AgentCore Policy is bypassed.

## User story

As Venkat (DevOps), I want an automated test that sends write statements straight to Athena and shows Lake Formation refuses them, so that the second layer of write protection is proven.

## Acceptance criteria (EARS)

1. When INSERT, UPDATE, DELETE, MERGE, CREATE TABLE AS, DROP TABLE and ALTER TABLE are sent to Athena through the identity-aware workgroup by a user in a permitted group, Lake Formation shall refuse each with an access error.
2. When the refusals are complete, the table row counts shall be unchanged from before the test.
3. Where identity_mode is group_fallback, the script shall run the same checks using the group roles.
