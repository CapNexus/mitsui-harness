# Quota request and 15-user concurrency test

Confirm the Bedrock quota request is granted and that 15 concurrent users see no throttling.

## User story

As a team lead, I want the assistant to hold up under a team's normal load, so that analysts are not blocked by throttling.

## Acceptance criteria (EARS)

1. When 15 concurrent users each submit a question, the system shall return answers with no Bedrock throttling errors.
2. If any Bedrock throttling error is recorded during the test, then the test shall fail and shall report the count.
3. Where the quota increase has not been granted, the test shall not run and shall report the pending request.
