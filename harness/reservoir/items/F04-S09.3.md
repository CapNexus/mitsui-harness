# Confirm the DMS login is not privileged (DBA check)

DBAs run the Appendix A2 check and send the output, proving the read-only DMS login (DEP-09) has no sysadmin rights and only the minimum database permissions.

## User story

As Venkat (DevOps), I want the DBAs to confirm the DMS login is read-only, so that DMS cannot change or over-read the Mitsui source databases.

## Acceptance criteria (EARS)

1. When the DBAs run the Appendix A2 check, the system shall record that IS_SRVROLEMEMBER('sysadmin', 'dms_wda_ro') returns 0.
2. When the DBAs run the Appendix A2 check in each database, the system shall record that the login holds only db_datareader, VIEW DATABASE STATE and VIEW DEFINITION.
3. When the DBA sends the query output, the system shall save it as evidence under evidence/F04/first-loads/.
