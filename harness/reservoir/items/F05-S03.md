# Register tables in the catalog and load descriptions

Load every approved table, its descriptions and its join hints into the Glue Data Catalog the same way on every run.

## User story

As Venkat (DevOps), I want a loader that registers every approved table in the Glue Data Catalog and writes descriptions and join hints from the repo files, so that the catalog is rebuilt the same way every time.

## Acceptance criteria (EARS)

1. When the loader runs, the loader shall register every table in approved_table_list in the Glue Data Catalog using the target names from wda_meta.name_map.
2. When the loader runs, the loader shall write table comments and column comments from config/descriptions.yaml.
3. When a column is a key column in config/crosswalk.yaml, the loader shall write a join hint on that column that names the crosswalk table.
4. If a description has source: draft, then the loader shall prefix the comment with "DRAFT:".
5. When the loader runs again with the same inputs, the loader shall leave the catalog unchanged.
6. The loader shall document in the README whether join hints are stored in comment text or in Glue column parameters.
