# Build the AWS Budgets alert

Define a monthly AWS budget with email alerts to Mitsui's billing contact so spend never surprises anyone.

## User story

As Mike (project manager), I want a monthly AWS budget with email alerts to Mitsui's billing contact, so that AWS spend, which Mitsui pays directly, never surprises anyone.

## Acceptance criteria (EARS)

1. When the budget stack is synthesized, it shall create a monthly cost budget for the amount in budget_monthly_usd.
2. The budget notifications shall email billing_contact_email at 80% of actual spend and at 100% of forecast spend.
3. If budget_monthly_usd or billing_contact_email is still TBD when synth runs for the POC stage, then synth shall fail with a message naming the parameter.
