# Confirm Teams answer latency from the dashboard report

Show that typical Teams answers arrive within 60 seconds, confirmed by the pilot lead from the dashboard report.

## User story

As the pilot lead, I want latency confirmed from the dashboard so that the 60-second target is judged on real pilot use.

## Acceptance criteria (EARS)

1. When the pilot dashboard report is produced, the system shall show the typical Teams answer time as 60 seconds or less.
2. When the report is reviewed, the pilot lead shall confirm the result in writing.
3. When the confirmation is made, the system shall save the dashboard report as evidence.
