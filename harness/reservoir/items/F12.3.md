# Bedrock invocation logging

Turn on Bedrock model invocation logging to an encrypted destination so each model call is recorded.

## User story

As an auditor, I want every Bedrock model invocation logged, so that each question's model activity can be reviewed.

## Acceptance criteria (EARS)

1. When a Bedrock model is invoked, the system shall write an invocation log record.
2. The system shall encrypt the Bedrock invocation log with the customer-managed KMS key.
3. If the log destination is unavailable, then the system shall raise an error metric for the dashboard and alarms.
