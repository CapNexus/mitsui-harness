# Deploy the load schedule to the POC account and confirm the first unattended run

Deploy an EventBridge schedule that starts the daily load Step Functions execution at the start of the agreed window in America/Chicago, and confirm the first scheduled run starts with no manual action.

## User story

As Noah Jackson (Mitsui), I want the daily load to start by itself at the start of the agreed window, so that nobody has to start it and it does not compete with our batch jobs.

## Acceptance criteria (EARS)

1. When the schedule is deployed to the POC account, the system shall define an EventBridge schedule that fires at the start of `load_window` in the `America/Chicago` time zone.
2. When `aws scheduler get-schedule` is run for the deployed schedule, the system shall return a schedule expression and time zone that match `load_window`.
3. While a date in `load_blackout_dates` applies, the system shall not start a scheduled load.
4. When the schedule fires for the first time (Dec 1 or Dec 2), the system shall start the Step Functions execution with no manual start.
