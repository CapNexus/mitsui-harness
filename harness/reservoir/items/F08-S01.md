# Define the tool contract, limits and names

Write one contract for the four tools so that the Lambdas, Gateway, Policy, prompt and runbook use the same names and limits.

## User story

As Soma (solution architect), I want one written contract for the four tools (names, inputs, outputs, limits and errors), so that all components use the same names and numbers.

## Acceptance criteria (EARS)

1. When the contract is written, docs/tool-contract.md and schemas/tools/*.json shall define list_tables, describe_columns, sample_rows and run_select with inputs, outputs, limits and errors.
2. The contract shall read all limits and timeouts from config/parameters.md at deploy time and shall not hard-code them.
3. The contract shall state how each tool behaves under identity_mode propagated and group_fallback.
4. The contract shall use the name run_select everywhere and not run_select_query.
