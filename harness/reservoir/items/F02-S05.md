# Write and test the teardown script

Provide a script that removes every POC resource and leaves the Control Tower landing zone alone, so Mitsui can stop paying after the readout and redeploy later.

## User story

As Venkat (DevOps), I want a script that removes every POC resource and leaves the Control Tower landing zone alone, so that Mitsui can stop paying for the POC after the readout and redeploy it later from the repository.

## Acceptance criteria (EARS)

1. When scripts/teardown.sh runs with --dry-run, the script shall list every stack it would delete in dependency order, match the stacks listed by cdk list, and change nothing.
2. When the script runs for real in the sandbox, it shall empty S3 buckets first, delete all POC stacks, and leave Control Tower resources unchanged.
3. After a real run, aws cloudformation list-stacks shall show no active POC stacks and no change to stacks named AWSControlTower* or StackSet-AWSControlTower*.
