# Add the checker for the completed approved table list

Provide scripts/check-approved-tables.sh, which fails when any row lacks a decision or a required MEPWELL table is missing or not approved.

## User story

As Venkat (DevOps), I want a check that rejects an incomplete approved table list, so that nothing downstream uses a list with undecided rows or without the MEPWELL tables.

## Acceptance criteria (EARS)

1. When every row in config/approved-tables.yaml has a decision of Approved, Approved with masking or Not approved, and the MEPWELL well hub and crosswalk tables are Approved, the system shall exit 0.
2. If any row has an empty decision, the system shall exit non-zero and name the row.
3. If the MEPWELL well hub or a crosswalk table is missing from the list or is not Approved, the system shall exit non-zero and name the table.
4. If a decision value is not one of the three allowed values, the system shall exit non-zero.
