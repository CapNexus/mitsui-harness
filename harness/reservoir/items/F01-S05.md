# Send the weekly status report

Generate a weekly status report from the register, RAID log and plan so the sponsor sees what is done, late and needed.

## User story

As the Mitsui sponsor, I want a weekly status report every Monday at 3:00 PM Eastern, so that I know what is done, what is late and what I need to do.

## Acceptance criteria (EARS)

1. When scripts/generate-status-report.sh --week <n> runs, the script shall produce a file with sections for work done, work planned, dependencies due this week with their status, slipped items with cause, and open decisions.
2. When a report is ready, Mike (PM) shall review it and send it by Monday 3:00 PM Eastern to every kick-off attendee, with the sent email saved in user-stories/evidence/F01/status-reports/.
3. If a week has no report, then scripts/check-status-reports.sh shall log the miss in the RAID log.
