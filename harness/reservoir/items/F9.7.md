# Refuse non-SELECT requests before they reach Athena

Add a SELECT-only check on every SQL statement and a refusal response, so no write or DDL statement reaches Athena.

## User story

As a data owner, I want the assistant to be read-only, so that nobody can change or delete well data through it.

## Acceptance criteria (EARS)

1. If a request asks to insert, update, delete or alter data, then the system shall refuse in the answer.
2. If a generated statement is not a single SELECT statement, then the system shall block it before it is sent to Athena.
3. When a statement is blocked, the system shall log the blocked statement and the reason.
