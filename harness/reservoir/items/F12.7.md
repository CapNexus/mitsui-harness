# Verify test alarm reaches every recipient

Verify in the deployed environment that a test alarm is delivered to every recipient on the Mitsui distribution list.

## User story

As an operator, I want proof that a test alarm reaches everyone on the distribution list, so that I know real alarms will be seen.

## Acceptance criteria (EARS)

1. When a test alarm is triggered, the system shall deliver an email to every recipient on the Mitsui distribution list.
2. If any recipient does not receive the test alarm, then the verification shall report that recipient as failed.
