# Create the D1 draft checker script

Provide a mechanical check that a D1 draft has the required sections and question counts.

## User story

As Mike (CapNexus project manager), I want a script that checks a D1 draft, so that I can trust the draft is complete before I review it.

## Acceptance criteria (EARS)

1. When `scripts/check-d1-draft.sh` is run on a D1 draft, the system shall verify that the project plan, dependency owners and question set outline headings are present.
2. When `scripts/check-d1-draft.sh` is run on a D1 draft, the system shall verify that the outline has about 7 questions per database and 9 joins.
3. If a required heading or question count is missing, the system shall exit non-zero and name what is missing.
4. When the draft meets all checks, the system shall exit 0.
